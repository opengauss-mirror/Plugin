# DML

<!-- md-trans-meta sourceCommit=unknown translatedAt=2026-10-27T11:01:10.519Z pushedAt=2026-10-27T11:16:46.327Z nl=2 -->

DML (Data Manipulation Language) is used to manipulate data in database tables, such as inserting, updating, querying, and deleting data.

## Notes

- This section covers only the multi-node parallel features newly added by spqplugin. The original openGauss syntax has not been deleted or modified.

## Inserting Data

Inserting data means adding one or multiple records to a database table. For details, see [INSERT](spqplugin-INSERT.md).

## Modifying Data

Modifying data means updating one or more records in a database table. For details, see [UPDATE](spqplugin-UPDATE.md).

## Deleting Data

Deleting data means removing one or multiple records from a database table. For details, see [DELETE](spqplugin-DELETE.md).
