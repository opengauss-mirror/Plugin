# PERFORMANCE_SCHEMA.EVENTS_STATEMENTS_CURRENT

<!-- md-trans-meta sourceCommit=unknown translatedAt=2026-07-30T06:23:17.334Z pushedAt=2026-09-12T04:44:11.479Z -->

The PERFORMANCE_SCHEMA.EVENTS_STATEMENTS_CURRENT view is compatible with the corresponding MySQL view and is created only in database B. It displays information related to the current user's queries, with fields storing the information from the most recent execution.

>[!NOTE] Note
>
>- Many columns in openGauss have no corresponding information in MySQL, or the output is not supported. To maximize compatibility, these columns are filled with NULL.
>- The underlying access involves the pg_stat_activity, dbe_perf.statement, and dbe_perf.statement_history tables. Information from the dbe_perf.statement and dbe_perf.statement_history tables (such as digest_text, schema_name, etc.) can be displayed only when the relevant permission requirements are met and the associated configuration parameters are enabled, such as track_stmt_parameter=on, track_stmt_stat_level is set, and enable_thread_pool = off.
>- If the query has finished executing and query_id and unique_sql_id are cleared, the related information from the dbe_perf.statement and dbe_perf.statement_history tables cannot be displayed.
