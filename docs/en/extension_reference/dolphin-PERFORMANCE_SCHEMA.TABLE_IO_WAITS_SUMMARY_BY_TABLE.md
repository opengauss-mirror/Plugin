# PERFORMANCE_SCHEMA.TABLE_IO_WAITS_SUMMARY_BY_TABLE

<!-- md-trans-meta sourceCommit=unknown translatedAt=2026-07-30T06:24:23.567Z pushedAt=2026-09-12T05:26:24.671Z -->

The PERFORMANCE_SCHEMA.TABLE_IO_WAITS_SUMMARY_BY_TABLE view provides statistics on I/O operations for table data files. It is compatible with the MySQL view of the same name and is created only in B databases.

>[!NOTE] Note
>
>- Many columns do not have corresponding information in openGauss compared with MySQL, or their output is Not Supported. To maintain maximum compatibility, these columns are filled with NULL.
>- The underlying layer accesses DBE_PERF.FILE_IOSTAT, where the statistical information for miniotim, avgiotim, and maxiowtm does not distinguish between read and write operations, whereas MySQL distinguishes among read, write, wait, and misc for min, max, and avg statistics. To present as much information as possible, the same data is used for display across all categories.
>- Unlike MySQL, which displays I/O wait data for all tables and shows all zeros when no data exists, this view only displays information for tables that have I/O wait events.
