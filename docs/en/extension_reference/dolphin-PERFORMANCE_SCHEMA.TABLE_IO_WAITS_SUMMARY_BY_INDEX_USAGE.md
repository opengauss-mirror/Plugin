# PERFORMANCE_SCHEMA.TABLE_IO_WAITS_SUMMARY_BY_INDEX_USAGE

<!-- md-trans-meta sourceCommit=unknown translatedAt=2026-07-30T06:24:22.475Z pushedAt=2026-09-12T05:24:38.393Z -->

The PERFORMANCE_SCHEMA.TABLE_IO_WAITS_SUMMARY_BY_INDEX_USAGE view provides I/O statistics for index data files. It is compatible with the MySQL view of the same name and is created only in database B.

>[!NOTE]Note
>
>- Many columns have no corresponding information in openGauss compared with MySQL, or the output is Not supported yet. To maintain maximum compatibility, these columns are filled with NULL.
>- The underlying layer accesses DBE_PERF.FILE_IOSTAT, where the statistics of miniotim, avgiotim, and maxiowtm do not distinguish between read and write operations. However, MySQL distinguishes read, write, wait, and misc to calculate min, max, and avg. To present as much information as possible, the same data is used for display.
>- Unlike MySQL, which displays I/O wait data for all indexes (showing all zeros if no data exists), this table displays only the index information that has I/O wait events.
