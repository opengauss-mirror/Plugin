# PERFORMANCE_SCHEMA.EVENTS_STATEMENTS_HISTORY

<!-- md-trans-meta sourceCommit=unknown translatedAt=2026-07-30T06:23:20.258Z pushedAt=2026-09-12T04:45:16.093Z -->

The PERFORMANCE_SCHEMA.EVENTS_STATEMENTS_HISTORY view is compatible with the corresponding MySQL view and is created only in B databases.

> [!NOTE] Note
>
> - For many columns, openGauss does not have information corresponding to MySQL, or the output is not supported. To maximize compatibility, these columns are filled with NULL.
> - The underlying access involves the pg_stat_activity, dbe_perf.statement, and dbe_perf.statement_history tables. Relevant permission requirements must be met, and related configuration parameters must be enabled, such as track_stmt_parameter=on, setting track_stmt_stat_level, and enable_thread_pool = off.
> - Unlike MySQL, this table records only successfully executed statements and does not record failed statements.
> - Similar to MySQL behavior, if a background process has been closed, the relevant information is not displayed.
