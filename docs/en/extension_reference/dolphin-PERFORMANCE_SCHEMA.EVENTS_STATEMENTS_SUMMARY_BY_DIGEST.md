# PERFORMANCE_SCHEMA.EVENTS_STATEMENTS_SUMMARY_BY_DIGEST

<!-- md-trans-meta sourceCommit=unknown translatedAt=2026-07-30T06:23:39.122Z pushedAt=2026-09-12T04:50:49.781Z -->

The PERFORMANCE_SCHEMA.EVENTS_STATEMENTS_SUMMARY_BY_DIGEST view is compatible with the corresponding MySQL view and is created only in the B database. It is used to obtain information about executed statements (normalized SQL) on the current node.
>[!NOTE] Note
>
>- Many columns in openGauss do not have corresponding information in MySQL, or the output is not currently supported. To maintain maximum compatibility, these columns are filled with NULL.
>- The underlying layer accesses the dbe_perf.statement and dbe_perf.statement_history tables. Relevant permission requirements must be met, and related configuration parameters must be enabled, such as track_stmt_parameter=on, track_stmt_stat_level must be set, and enable_thread_pool = off.
>- The upper limit of statements displayed by this view is subject to the upper limit of dbe_perf.statement, which can be adjusted through the GUC parameter instr_unique_sql_count.
